# Deus

עוזר קולי שולחני ל-Windows, מבוסס Whisper (תמלול מקומי, לא שולח כלום
לענן) שמזהה את מילת ההפעלה **"דאוס"** (וכמה וריאציות נוספות שדומות לה
בהגייה - ראו למטה) ומבצע פקודות קוליות: פתיחת אפליקציות והרצת
סקריפטים, חיפוש בגוגל/יוטיוב/תמונה (reverse image search), תרגום
לעברית עם הקראה, תמלול חופשי להקלדה, הקלטה והפעלה של מאקרואים (רצפי
מקלדת/עכבר), הקלטת שמע חופשית, הקלטת מסך לוידאו, "קליקר" אוטומטי,
הורדת סרטוני יוטיוב, ניקוי זיכרון (RAM), נעילת מחשב, כיבוי עצמי,
מעבר למצב "חסכון" (מודל תמלול קל יותר על CPU), פתיחת אתרים, שליטה
במדיה, ופתיחה/מיקוד של AI Engine מבוסס דפדפן (כרגע: Gemini ב-Chrome).

מוצג כדמות שקופה ומונפשת (GIF) שתמיד על המסך, שמשנה אנימציה לפי מה
שקורה - **idle** (רגיל) / **listening** (מאזין) / **thinking** (מבצע
פקודה) / **talking** (דאוס "אומר" לכם משהו) / **shut1 → shut2**
(מושתק) - עם קרוס-פייד חלק בין כל מעבר.

## התקנה

> **חשוב להבין - יש כאן שתי קהלי יעד שונים לגמרי:**
> - **אתם (מפתחים/בונים את התוכנה)** - צריכים את כל מה שבסעיף הזה
>   (`pip install -r requirements.txt`, ואם רוצים - Inno Setup) על
>   המחשב **שעליו אתם בונים** את `Deus.exe`.
> - **משתמש קצה שמקבל מכם את `DeusSetup.exe`** - **לא צריך שום דבר
>   מכל זה**. לא Python, לא pip, לא להריץ שום פקודת התקנה בעצמו.
>   `--onefile` של PyInstaller אורז את הפייתון עצמו + כל חבילות ה-pip
>   שהתקנתם + את ה-assets + config.json ברירת המחדל, **לתוך קובץ
>   ה-exe היחיד עצמו** - זה בדיוק מה שמאפשר למתקין (`installer.iss`)
>   להעתיק רק אותו קובץ אחד ולסיים. הדבר החיצוני היחיד שהתוכנה צריכה
>   מעבר לזה (`ffmpeg`, להקלטת מסך/הורדת סרטונים) **מוריד את עצמו
>   אוטומטית** בפעם הראשונה שצריך אותו - ראו "כלי חיצוני נוסף" למטה.
>   במילים אחרות: **כן, משתמש רגיל שמריץ רק את `DeusSetup.exe` יסתדר
>   מצוין**, בלי לדעת בכלל שפייתון קיים.

### הרצה מתוך הקוד (למפתחים) - מומלץ עם סביבה וירטואלית נקייה

```powershell
conda deactivate            # אם יש conda פעיל - כדי לא "להתנגש" עם venv
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

עדיף תמיד `venv` נקי (לא סביבת `conda`/מערכת גלובלית) - חלק מהתלויות
(כמו `faster-whisper`, `PySide6`) רגישות לגרסת Python/סביבה, וסביבה
וירטואלית ייעודית מונעת התנגשויות עם חבילות אחרות שכבר מותקנות אצלכם.

```powershell
pip install -r requirements.txt
```

### תלויות ליבה (חובה)
`PySide6`, `faster-whisper`, `sounddevice`, `numpy`, `keyboard`, `pywin32`.

### תלויות אופציונליות (מומלצות, לא שוברות כלום בלעדיהן)
| חבילה | לשם מה | בלעדיה |
|---|---|---|
| `opencv-python`, `mss`, `pyautogui` | "דיבור אוטומטי" (לחיצה אוטומטית על כפתור המיקרופון/הקלדה בג'מיני), וגם **חיפוש תמונה בגוגל** (צילום מסך) | הפיצ'רים מדולגים בשקט |
| `rapidfuzz` | התאמה מקורבת (fuzzy) מהירה יותר לזיהוי מילות הפעלה/פקודות | נופל אוטומטית ל-`difflib` המובנה, קצת יותר איטי |
| `mouse` | הקלטה/הפעלה של **תזוזות ולחיצות עכבר** במאקרואים, וגם **הקליקר האוטומטי** | מאקרואים עדיין עובדים בלי אירועי עכבר; הקליקר נופל ל-`pyautogui` אם קיים |
| `pygame-ce` | ניגון צלילים **עם שליטה אמיתית בעוצמת קול** (0-100%) | צלילים עדיין מנוגנים (דרך `winsound`), אבל תמיד בעוצמה מלאה - עוצמת הקול משפיעה רק על "מנוגן" מול "מושתק" (0%) |
| `psutil` | **ניקוי זיכרון/RAM** ("דאוס נקה זיכרון") | הפקודה מדלגת בשקט עם אזהרה בלוג |
| `yt-dlp` | **הורדת סרטוני יוטיוב** ("דאוס הורד סרטון") | הפקודה מדלגת בשקט עם אזהרה בלוג |
| `pyttsx3` | **הקראת תרגומים בקול** (SAPI5 מקומי, לא דורש אינטרנט) | התרגום עדיין מוצג בבועה על המסך, פשוט בלי הקראה |
| `pyinstaller` | בניית `dist\Deus.exe` | נדרש רק לבנייה, לא להרצה |

### כלי חיצוני נוסף (לא pip) - אבל **לא צריך לדרוש שום דבר מהמשתמש הסופי**
`ffmpeg` נדרש עבור **הקלטת מסך** ("דאוס הקלטת מסך") ולמיזוג וידאו+אודיו
באיכות הכי טובה ב-**הורדת סרטונים**. זו לא חבילת pip - PyInstaller לא
אורז אותה אוטומטית. כדי שמשתמש שמתקין רק את `DeusSetup.exe` לא יצטרך
להתקין שום דבר בעצמו, `ai_engine/ffmpeg_utils.py` **מוריד אותה
אוטומטית, פעם אחת, ברקע**, בפעם הראשונה שאחת מהתכונות האלה בפועל
מופעלת (בילד "essentials" רשמי וחינמי, ~80MB, נשמר תחת
`%LOCALAPPDATA%\Deus\ffmpeg`) - בדיוק כמו ש-`Deus.exe` עצמו לא דורש
התקנת Python. אם ההורדה נכשלת (אין אינטרנט וכו') - התכונה הספציפית
מדלגת בשקט עם אזהרה בלוג, בלי להשפיע על שאר האפליקציה.

> **הערה ל-Python 3.13/3.14:** אם `pip install pygame` נכשל עם שגיאת
> קומפילציה (`No module named 'distutils.msvccompiler'` וכו') - זה כי
> אין wheel מוכן מראש לגרסת ה-Python שלכם. פתרון: `pygame-ce`
> (Community Edition) שכבר ברשימת ה-requirements - זהה לגמרי מבחינת
> קוד (`import pygame`) אבל עם wheels עדכניים יותר. אם גם היא נכשלת -
> אפשר פשוט למחוק את השורה, הכל ימשיך לעבוד בלי שליטת עוצמה הדרגתית.

### בניית קובץ הפעלה + מתקין
```powershell
.\build_exe.bat
```
בונה `dist\Deus.exe` עם PyInstaller, ואם מותקן [Inno Setup](https://jrsoftware.org/isdl.php)
(חינמי) - גם `installer_output\DeusSetup.exe` עם קיצורים, תפריט התחל
והסרת התקנה מסודרת.

> **טיפ לפני הפצה למשתמשים אמיתיים**: כדאי לבדוק את `DeusSetup.exe`
> על מחשב/VM **בלי Python מותקן בכלל** - זו הדרך הכי אמינה לוודא
> ש-PyInstaller באמת ארז הכל (לפעמים חבילות מסוימות דורשות
> `--hidden-import`/`--collect-all` נוספים כדי שהוא "יתפוס" את כל
> התלויות שלהן - למשל `nvidia.cublas`/`nvidia.cudnn`/`ctranslate2`
> כבר מתועדים למעלה בהערת ה-GPU; אם משהו חדש (`psutil`, `yt-dlp`,
> `pyttsx3`, `mss`, `opencv-python`) "נעלם" רק ב-exe הבנוי אבל עובד
> תקין בהרצה ישירה עם `python main.py` - זה בדיוק הסימן לזה, ואפשר
> להוסיף לו `--collect-all <שם_החבילה>` ב-`build_exe.bat`).

**הסרת התקנה**: `installer.iss` מוחק אוטומטית את `%LOCALAPPDATA%\Deus`
(הגדרות/לוגים) בהסרה. מודלי התמלול שדאוס מוריד (כמה ג'יגהבייט,
ל-`%USERPROFILE%\.cache\huggingface\hub`, תיקיית מטמון *משותפת*
ל-Hugging Face) **נשמרים בכוונה** - כלי AI אחרים על המחשב עשויים
להשתמש באותה תיקייה. תוכנת ההסרה **שואלת בפירוש** (כבוי כברירת
מחדל - צריך ללחוץ "כן" במפורש) אם למחוק אותם, ובמפורש **מוחקת רק את
שלוש תיקיות המודלים הספציפיות שדאוס עצמו עשוי ליצור** (לפי שם מדויק:
`models--ivrit-ai--whisper-large-v3-ct2`,
`models--Systran--faster-whisper-medium`,
`models--Systran--faster-whisper-small`) - **לעולם לא** את כל תיקיית
ה-`hub` המשותפת, כדי לא לפגוע במודלים של תוכנות אחרות שנמצאים שם.

## איך זה עובד

1. חלון שקוף עם GIF תמיד מוצג על המסך.
2. ברקע, `WakeWordDetector` מאזין למיקרופון בצ'אנקים קצרים (ברירת
   מחדל: 2 שניות) ומתמלל מקומית עם `faster-whisper` (GPU אם יש,
   נופל ל-CPU אוטומטית אם אין).
3. "דאוס" הוא **רק מילת מפתח** - היא לא מבצעת שום פעולה בעצמה. המילים
   *אחריה* נבדקות מול טבלת הפקודות. אם אין התאמה - לא קורה כלום,
   בכוונה (זה מונע false-positive מציק).
4. לכל פקודה יש **כמה ניסוחים טבעיים מזוהים מראש** (ברירת מחדל עשירה
   ב-`commands.py`, בנוסף למה שתגדירו ב-`config.json`), וגם שכבת
   "התאמה לפי שורש" (`fuzzy_match.py`) שמזהה נטיות/גופים/זמנים שונים
   של אותה מילה (למשל "פתח"/"תפתח לי"/"פתחי") - כדי שלא תצטרכו לשנן
   ניסוח מדויק.
5. פקודות שדורשות ארגומנט (חיפוש, שם אפליקציה/סקריפט/מאקרו/אתר) שזוהו
   *בלי* ארגומנט מיד אחריהן (למשל "דאוס חפש בגוגל" ואז הפסקה קצרה
   לפני מילות החיפוש) - לא מתבצעות מיד עם ארגומנט ריק. דאוס ממתין עד
   כמה צ'אנקים נוספים (`commands.argument_window_chunks`) ולוקח את מה
   שיגיע כארגומנט.
6. בכל זיהוי בפועל של מילת ההפעלה מתנגן "בליפ" קצר (`blip.mp3`/`.wav`).
7. בביצוע פקודה - האנימציה עוברת ל-`thinking`. כשדאוס "אומר" משהו
   (תחילת/סיום תמלול, לימוד/הפעלת מאקרו, הקלטה/קליקר, טעינת מודל) -
   עוברת ל-`talking` לאורך משך הצליל, ואז חוזרת לבד.
8. בהשתקה (`Ctrl+Alt+D` או מתפריט המגש) - עוברת ל-`shut1 → shut2`, ומודל
   ה-Whisper **משתחרר מהזיכרון** (GPU/CPU) כדי לפנות משאבים. כל מצב
   מתמשך פתוח (הקלטה/קליקר/הקלטת מסך) נעצר ונשמר אוטומטית. בביטול
   ההשתקה - המודל נטען מחדש אוטומטית ברקע.
9. **בהפעלה הראשונה** אחרי התקנה/עדכון, דאוס סורק אוטומטית אפליקציות
   נפוצות (וורד, כרום, כתבן, מחברת ועוד - `ai_engine/app_finder.py`)
   ומוסיף אותן ל"ניהול אפליקציות" בלי צורך בהגדרה ידנית - רץ פעם אחת
   בלבד (`config["_apps_auto_scanned"]`).
10. **המיקום של החלון על המסך נשמר אוטומטית** בכל פעם שגוררים אותו
    (`config["window"]["start_x"/"start_y"]`) - בהפעלה הבאה הוא יופיע
    באותו מקום בדיוק.
11. **אם נאמרת מילת ההפעלה "דאוס" שוב** לפני שדאוס הספיק לזהות פקודה
    (למשל כי הפקודה הראשונה לא נשמעה טוב) - דאוס **תמיד מתחיל חיפוש
    פקודה מחדש** מהמילים שאחרי ה"דאוס" השני, ולעולם לא מנסה להתייחס
    למילה "דאוס" עצמה כאילו הייתה חלק מפקודה/ארגומנט. אפשר פשוט לומר
    "דאוס" שוב בכל שלב כדי "להתחיל מחדש".

## מילת ההפעלה

בברירת המחדל דאוס מזהה כמה וריאציות של מילת ההפעלה עצמה (כדי לצמצם
פספוסים כתוצאה מתמלול לא מדויק של Whisper): **דאוס, דיוס, דעוס, דאוז,
Deus, Daus, נורס**. אפשר להוסיף/לערוך את הרשימה ב-`config.json` תחת
`"wake_words"`.

## פקודות קוליות

כל פקודה נאמרת בתבנית **"דאוס \<פקודה\> \<ארגומנט אם צריך\>"**. לכל
פקודה יש הרבה ביטויים מזוהים (נרדפות וניסוחים/נטיות שונות) - כדי
להתמודד עם דרכים שונות לנסח את אותה בקשה, ועם טעויות תמלול נפוצות.
אפשר לערוך/להוסיף ביטויים חופשית ב-`config.json` תחת `"commands"` -
הם מתמזגים (union) עם ברירות המחדל העשירות שכבר מוגדרות בקוד, בלי
לדרוס שינויים ידניים, וגם מתעדכנים אוטומטית לתוך ההגדרות השמורות של
המשתמש בעדכון קוד עתידי.

> **יתחיל** במצב חסכון גם בהפעלה הבאה - זה נשמר בנפרד מהמצב הנוכחי.

## ⚠️ ניקוי זיכרון (RAM) - חשוב לקרוא

הפקודה "דאוס נקה זיכרון" / "נקה ראם" / "סגור הכל" (`ai_engine/ram_cleaner.py`)
סוגרת תהליכים כבדים ומנקה זיכרון פנוי, בהשראת (לא זהה ל-) סקריפט
אופטימיזציה ל-Windows מבוסס batch/PowerShell. שני עקרונות בטיחות
נשמרים בקפידה:

1. **לעולם לא נוגעת ברשת/Wi-Fi/Bluetooth** - שום קוד בפונקציה הזו
   מכבה מתאמי רשת או שירותי רשת, בכל מצב.
2. **תהליכים ושירותים קריטיים תמיד מוגנים**, גם אם אינם ברשימת
   ההחרגה שלכם:
   - כל תהליכי הליבה של Windows: `explorer`, `dwm`, `csrss`,
     `winlogon`, **`services`** (Service Control Manager), `lsass`,
     `smss`, `svchost`, `conhost`, `system`, `registry` וכו'.
   - **כל תהליך/שירות שמכיל "omen" או "hp" בשמו** (תת-מחרוזת רחבה,
     בדיוק כמו בסקריפט המקורי) - זה כולל את **HP Omen Hub** ואת כל
     שירותי הבקרה על המאווררים (fan control), כמו
     `OmenCommandCenterBackground`, `HPOMENHsaService`,
     `HPNetworkBoosterService` ועוד. **חשוב במיוחד**: אם השירותים
     האלה נסגרים בטעות, השליטה במאווררים עלולה להיתקע/להיעצר עד
     ריסטארט מלא של המחשב - לכן ההגנה עליהם רחבה בכוונה ולא מוגבלת
     רק לשמות מדויקים.
   - `python`/`pythonw`, `powershell`/`pwsh`, `cmd` - כדי לא לסגור את
     דאוס עצמו או כלים שאתם עובדים איתם באותו רגע.
   - התהליך של דאוס עצמו (לפי PID, תמיד מוחרג).

מעבר לכך, שני שלבי ניקוי:
- **תהליכים כבדים מוכרים מראש** (רשימה קבועה ב-`_DEFAULT_TARGET_PROCESSES`,
  ניתנת להרחבה עם `config["ram_clean"]["extra_targets"]`) + **כל תהליך
  שצורך יותר מ-100MB** - נסגרים בכוח (`Stop-Process`/`kill`), חוץ
  מאלה שברשימת ההגנה למעלה.
- שאר התהליכים (קטנים/מוגנים) - רק "מנוקה" ה-working set שלהם
  (`EmptyWorkingSet`, שקול לניקוי RAM standby) בלי לסגור אותם.

**החרגות משלכם**: תפריט המגש **"ניקוי זיכרון > ניהול חריגים..."**
מאפשר להוסיף שמות תהליכים/אפליקציות נוספים שלעולם לא ייסגרו (למשל
תוכנת עריכה שאתם רוצים שתישאר פתוחה). תפריט **"ניקוי זיכרון > סגור
מצלמה בזמן ניקוי"** הוא טוגל נפרד (כבוי כברירת מחדל) שמשבית מצלמה
מובנית/USB כחלק מהניקוי - **לא קשור בשום צורה לרשת**. אפשר גם להריץ
ניקוי ידני מיידי דרך **"ניקוי זיכרון > נקה זיכרון עכשיו"**.

**דאוס עצמו**: כברירת מחדל, ניקוי הזיכרון **כולל את דאוס עצמו** -
הוא נסגר בסוף התהליך, בעדינות (לא kill), ו**רק אחרי** שכל שאר
הסגירות/הניקוי כבר בוצעו במלואן (`config["ram_clean"]["close_self"]`,
ברירת מחדל `true`). אפשר לבטל את זה דרך תפריט המגש **"ניקוי זיכרון >
כלול את דאוס עצמו בניקוי"**.

דורש `pip install psutil`. בלעדיה הפקודה מדלגת בשקט עם אזהרה בלוג.
נתמך רק ב-Windows.

## 🎬 הקלטת מסך

"דאוס הקלטת מסך" (`ai_engine/screen_recorder.py`) מקליט וידאו של המסך
דרך `ffmpeg` (חייב להיות מותקן ונגיש דרך PATH - [הורדה חינמית](https://ffmpeg.org/download.html)),
ושומר ל-`Downloads` עם תאריך ושעה בשם הקובץ (`deus_screen_recording_...mp4`).

- **טוגל עצמאי**: אמרו "דאוס הקלטת מסך" שוב כדי לעצור ולשמור.
  **בכוונה לא מושפעת מ"דאוס עצור"** הגנרי - כדי שאפשר יהיה להקליט
  מסך תוך כדי שימוש בפקודות אחרות שכן משתמשות ב"עצור" (למשל תמלול
  קולי) בלי שההקלטה תיפסק בטעות.
- לא לבלבל עם **"דאוס הקלט"** (`ai_engine/audio_recorder.py`) - זו
  הקלטת **שמע בלבד** מהמיקרופון, לא וידאו של המסך. הביטויים הקוליים
  של שתי הפקודות שונים בכוונה (הקלטת מסך תמיד כוללת את המילה "מסך")
  כדי שלא יתבלבלו זה בזה.
- **מיקרופון בהקלטה**: כבוי כברירת מחדל. אפשר להפעיל דרך
  `config["screen_record"]["include_mic"] = true` - דאוס ינסה לזהות
  אוטומטית את המיקרופון המוגדר כברירת מחדל ב-Windows (דרך
  `ffmpeg -list_devices`); אם הזיהוי נכשל, ממשיך להקליט בלי שמע במקום
  להיכשל על כל ההקלטה.
- אם `ffmpeg` לא נמצא - הפקודה מדלגת בשקט עם אזהרה בלוג, בלי לקרוס.

## 🐢 מצב חסכון (Whisper קל יותר)

"דאוס מצב חסכון" עובר למודל Whisper **"small" על CPU בלבד** (בלי
תלות בהגדרות ה-GPU/מודל הרגילות) - שימושי אם המודל הרגיל (שיכול
להיות GPU + מודל גדול כמו `large-v3`) גורם לעומס/חום/רעש מוגזם על
המחשב. "דאוס תחזור" חוזר למודל הרגיל.

- נגיש גם דרך קיצור מקשים גלובלי **Ctrl+Alt+P** (הפיך, לא תלוי
  בקונפיג) - למקרה שהתמלול הפחות מדויק במצב חסכון לא מזהה טוב מספיק
  את הפקודה הקולית "תחזור" בעצמה.
- תפריט המגש **"הפעל תמיד במצב חסכון"** קובע אם דאוס **יתחיל** ישר
  במצב חסכון בהפעלה הבאה (`config["whisper_start_in_economy_mode"]`) -
  מוגדר בנפרד מהמצב הנוכחי, ולא משתנה אוטומטית כשמחליפים מצב תוך כדי
  ריצה.
- גודל המודל/סוג החישוב במצב חסכון ניתנים לכיוונון:
  `config["whisper_economy_model_size"]` (ברירת מחדל `"small"`),
  `config["whisper_economy_compute_type"]` (ברירת מחדל `"int8"`).

## תפריט המגש (System Tray)

לחיצה ימנית על האייקון פותחת תפריט עם:

- הצג/הסתר, גודל, שקיפות, עוצמת קול, **העלם את דאוס אוטומטית**, השתקה
- הפעלה אוטומטית עם Windows, לוגים, דיבור אוטומטי, שינוי קיצור ה-AI
- **ניהול אפליקציות**, **ניהול סקריפטים**, **ניהול מאקרואים**
- **פתח אתר** (תפריט פתיחה מהירה לכל אתר מוגדר + "ניהול אתרים...")
- **ניקוי זיכרון** (סגור מצלמה בזמן ניקוי / כלול את דאוס עצמו / ניהול
  חריגים / נקה עכשיו)
- **טיימר כיבוי מחשב** (30/60/90/120 דקות, או זמן מותאם אישית) +
  **ביטול טיימר כיבוי** + **ברירת מחדל לכיבוי מחשב בקול** (דקות) -
  **פריטי תפריט בלבד, לא פקודות קוליות** (חוץ מברירת המחדל, שמשפיעה
  על הפקודה הקולית "דאוס כיבוי מחשב")
- **הפעל תמיד במצב חסכון** (טוגל - קובע את מצב ההפעלה הבא) + **מצב חסכון (עכשיו)** (טוגל נפרד - משנה מיידית, כמו Ctrl+Alt+P)
- **כלול מיקרופון בהקלטת מסך** (טוגל, מופעל כברירת מחדל)
- **הקרא תרגומים בקול (לא עובד)** - טוגל קיים, אבל יש תקלה ידועה
  זמנית בהקראה בפועל (ראו "פתרון תקלות נפוצות" למטה); בועת התרגום על
  המסך עדיין עובדת כרגיל
- מדריך הפעלה מובנה, **ומדריך פקודות** (רשימת כל הפקודות הקוליות,
  כולל הפעלת סקריפטים ומאקרואים - נפתח בחלון עצמאי רגיל שלא מתנגש
  עם שאר תפריט המגש)

## קונפיגורציה חשובה

הקובץ בפועל: `%LOCALAPPDATA%\Deus\config.json` (נוצר אוטומטית מ-
`config.json` הנצרב בתוך ה-exe, בהפעלה הראשונה). **עדכוני קוד עתידיים
ממזגים אוטומטית** מפתחות/ביטויים חדשים לתוכו, בלי לדרוס שינויים
שהמשתמש כבר עשה.

"whisper_economy_compute_type": "int8", // סוג חישוב במצב חסכון (תמיד CPU)

  "toggle_economy_mode": "ctrl+alt+p"   // מעבר מיידי בין מצב חסכון לרגיל
},
"sounds": {

  "dir": "assets/sounds",

## מאקרואים - איך זה עובד בפועל

1. **"דאוס תלמד מאקרו \<שם\>"** - מתחיל להקליט את כל אירועי המקלדת
   והעכבר (חבילות `keyboard`+`mouse`) עם חותמות זמן יחסיות.
2. מבצעים את הפעולות הרצויות (לחיצות, הקלדה, תזוזות עכבר).
3. **"דאוס עצור"** - עוצר את ההקלטה ושומר תחת \<שם\> (מוצג מיד בתפריט
   "ניהול מאקרואים" - קביעת מס' חזרות, מחיקה).
4. **"דאוס תפעיל מקרו \<שם\>"** - משחזר את הרצף בדיוק (עם אותם פערי
   זמן), חוזר לפי מספר החזרות שנקבע (ברירת מחדל: 1; אינסופי = עד
   "דאוס עצור" תוך כדי ריצה).

## הקלטת שמע חופשית וקליקר - איך זה עובד בפועל

- **"דאוס הקלט"** מתחיל להקליט מהמיקרופון (WAV גולמי, לא תלוי במודל
  Whisper). **"דאוס עצור"** עוצר ושומר לתיקיית `Downloads` עם שם קובץ
  כמו `deus_recording_2026-07-31_14-30-05.wav`.
- **"דאוס קליקר"** לוחץ שמאלית כל חצי שנייה (`commands.clicker_interval_sec`)
  במיקום העכבר הנוכחי, עד **"דאוס עצור"**.
- שני המצבים האלה, כמו מאקרו/תמלול, נעצרים אוטומטית גם בהשתקה
  (`Ctrl+Alt+D`), כדי לא להישאר "תקועים" ברקע בלי דרך לעצור אותם.
- שימו לב: הקלטת שמע חופשית פותחת זרם מיקרופון *נוסף* לזה שדאוס כבר
  מאזין דרכו למילת ההפעלה - ברוב המקרים זה עובד בסדר גמור (Windows
  WASAPI Shared תומך בכמה זרמים בו-זמנית), אבל אם יש לכם בעיות
  ספציפיות לדרייבר המיקרופון, בדקו את הלוג.

## פתרון תקלות נפוצות

- **`config.json` "נעלם" - הגדרות (מיקום חלון, אפליקציות שנסרקו וכו')
  לא נשמרות, ולוג מראה `FileNotFoundError: ... config.json`, ואפילו
  סריקת האפליקציות האוטומטית רצה מחדש בכל הפעלה** - זה קורה כשמשהו
  חיצוני מוחק את `%LOCALAPPDATA%\Deus\config.json` באמצע ריצה - הגורם
  השכיח ביותר: **תוכנת אנטי-וירוס שחושדת ב-exe לא-חתום** (`Deus.exe`
  שבניתם בעצמכם, בלי חתימה דיגיטלית רשמית) ומסירה/מבודדת קבצים
  שנוצרו על ידו כאמצעי זהירות. **תוקן בקוד**: `_persist_config_value`
  עכשיו בונה מחדש את `config.json` אוטומטית אם הוא חסר, במקום פשוט
  להיכשל בשקט - כך שההגדרות **הבאות** יישמרו כרגיל (הגדרות שכבר
  אבדו, כן צריך להגדיר מחדש). כדי שזה לא יקרה שוב מלכתחילה, כדאי
